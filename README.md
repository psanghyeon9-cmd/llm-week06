# 6주차 개인 과제

## 과제 1 진행 방법

1. 실행 전에 테스트 문장 5건의 정답과 프롬프트 기준을 먼저 정해 `assignment1/report.md`에 기록했습니다.
2. `assignment1/run_index.csv` 순서대로 Gemini 웹 UI에서 매번 새 대화를 열어 실행했습니다.
3. 해당 `inputs/` 파일의 전체 내용을 한 번에 붙여넣어 실행했습니다.
4. 답변은 수정하지 않고 같은 이름의 `outputs/*.txt` 파일에 저장했습니다.
5. 입력과 응답이 함께 보이도록 화면을 캡처해 `captures/*.png`로 저장했습니다. 한 화면에 담기지 않으면 `_part1`, `_part2`처럼 나눠 저장하도록 정했습니다.
6. 실행 서비스와 모드를 `run_index.csv`에 기록했습니다. 화면에서 확인할 수 없는 모델명과 실행 시각은 임의로 채우지 않았습니다.
7. 21회 실행 결과를 평가해 리포트의 결과·분석·결론을 작성했습니다.

결과를 본 뒤 정답이나 프롬프트를 중간에 바꾸지 않았습니다.
